                                                                                                    
 Usage: certinext parent-dcv-status [OPTIONS]                                                       
                                                                                                    
 Show DCV status and expiry for domains that require direct DCV validation.                         
                                                                                                    
 Includes account-level parents (no registered ancestor) and, by default,                           
 zone-boundary subdomains whose NS records block DCV inheritance from a parent.                     
                                                                                                    
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --pattern              REGEX   Filter domains by regex before identifying parents (re.fullmatch, │
│                                case-insensitive)                                                 │
│ --status               STATUS  Filter output by DCV status category: all (default), verified,    │
│                                expiring, pending, expired                                        │
│                                [default: all]                                                    │
│ --expiring-days        DAYS    Number of days ahead to flag a domain as expiring soon (used by   │
│                                --status expiring and the ! indicator; default: 30)               │
│                                [default: 30]                                                     │
│ --no-ns-check                  Skip DNS NS lookups when identifying domains that need direct     │
│                                DCV. By default NS records are checked so zone-boundary           │
│                                subdomains (those with their own NS records) are included even    │
│                                when a parent domain is registered. Requires dnspython (pip       │
│                                install certinext).                                               │
│ --help                         Show this message and exit.                                       │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
