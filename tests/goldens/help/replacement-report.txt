                                                                                                    
 Usage: certinext replacement-report [OPTIONS]                                                      
                                                                                                    
 List currently valid certificates that need replacing after a CA distrust.                         
                                                                                                    
 By default classifies on the issuing CA alone (instant, from the orders                            
 report). Criteria come from built-in defaults (the October 2026 eMudhra                            
 ECC distrust), the "replacement" table in config.toml, and the flags                               
 above. Read-only. Exits 1 if any certificate could not be inspected.

│                                                     evaluates the key and chain signals (so      │
│                                                     disagreements are detected), and adds SANs,  │
│                                                     key size, and who ordered it. Two requests   │
│                                                     per certificate.                             │
│ --all                                               Also list certificates that do not need      │
│                                                     replacing (to measure progress)              │
│ --latest-only                                       Hide certificates superseded by a newer      │
│                                                     valid certificate for the same names         │

│                                                     repeatable, replaces config                  │
